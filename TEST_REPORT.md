# Проверка приложения — 16.11.2026

## Автоматические проверки: пройдены

- 800 уникальных идентификаторов и текстов; у каждого три различных варианта ответа, пояснение и источник.
- Независимый пересчёт 320 численных ответов с точностью округления.
- Три полных круга, 2400 ответов: отсутствие повторов ID внутри круга; по 20 заданий, 12 + 8; восстановление состояния после каждого ответа.
- Защита от повторного клика, экспорт/импорт состояния и отклонение некорректного импорта.
- Service Worker: полный предварительный кэш, офлайн-навигация, выдача файлов, очистка только своего кэша, сообщение о готовности и отсутствие перехвата внешних запросов. Это модульная проверка с моделью Cache API.

## Ручная проверка в браузере Chrome

- Пройден тест из 20 вопросов: объяснения правильных и неправильных ответов, итоговый разбор 14 ошибок при 6 верных ответах.
- Перезагрузка на объяснении сохранила выбранный ответ.
- Обновление версии кэша через кнопку и подтверждение сохранило очередь и результаты.
- Кнопка следующих 20 вопросов открыла второй тест.
- Сервер локального просмотра остановлен. Перезагрузка приложения продолжила показывать второй тест из кэша; выбор правильного ответа показал объяснение. Проверка выполнена без доступного сервера приложения, а не через системный авиарежим.

## Ещё не проверено на устройствах

Установка и длительное хранение на реальных iPhone/iPad и Android, поведение при очистке данных ОС, работа на опубликованном GitHub Pages и миграция между устройствами. Исходники готовы к публикации, но репозиторий и публичный URL не созданы. Адаптивная вёрстка и манифест включены; эти проверки не заменяют испытаний на физических устройствах.
